# Запятые — тренажёр пунктуации (6 класс)

Это веб-приложение (PWA): ставится на iPhone как обычное приложение и работает без интернета.

## Как установить на iPhone

1. Один раз выложить папку в интернет по HTTPS (без этого iPhone не сохранит приложение для офлайна).
   **GitHub Pages:** создать репозиторий, загрузить все файлы этой папки,
   Settings → Pages → Branch: main → Save. Адрес будет вида https://ИМЯ.github.io/РЕПОЗИТОРИЙ/
2. Открыть этот адрес на iPhone **в Safari**.
3. Нажать «Поделиться» → «На экран „Домой“». Включить «Открыть как веб-приложение», если такой переключатель есть.
4. Открыть приложение с иконки один раз при интернете. После этого оно работает без сети — в России, за границей, в самолёте.

## Важно
- Прогресс хранится на самом телефоне. Если удалить иконку, прогресс тоже удалится.
- Как обновить приложение: залить новые файлы и поменять версию в `sw.js` (`punct-v1` → `punct-v2`).
  Обновление подтянется, когда приложение откроют при интернете.

## Как добавить задания
В `index.html`, массив `TOPICS`: пишем предложение со всеми правильными знаками, например
`{s:'Мама, можно я пойду гулять?', e:'Объяснение'}`. Тире пишется отдельно: `Москва — столица`.
